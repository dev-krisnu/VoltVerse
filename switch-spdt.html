Switch #9: Single Pole Double Throw (SPDT)

Dual-path selector switch (1 Input COM Pole, 2 Output Throws: L1 / L2)

Operational Purpose

A Single Pole Double Throw (SPDT) switch has one input terminal (Common - COM) and two output terminals (Throw 1 - L1, Throw 2 - L2). It connects the common line to either L1 or L2, allowing circuit changeover between two loads or operating paths without leaving the circuit completely disconnected.

Terminal Pinout Layout

COM

Common Supply Input

L1

Throw 1 Output

L2

Throw 2 Output

Switching Logic Break-Before-Make (BBM)
Application Class 2-Way / Changeover Control

Key Components

  • •
    Common Terminal Pivot (COM): Central copper post acting as the mechanical hinge for the internal wiper blade.
  • •
    Dual Output Contacts (L1 & L2): Silver-cadmium plated contact pads positioned on opposing ends of the contact travel arc.
  • •
    Spring Detent Mechanism: Internal compression spring providing tactile feedback and snap-action speed to minimize electrical arcing.
