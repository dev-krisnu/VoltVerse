Switch #8: Single Pole Single Throw (SPST)

Basic ON/OFF single circuit control switch (1 Input Pole, 1 Output Throw)

Operational Purpose

A Single Pole Single Throw (SPST) switch is the simplest type of electrical switch. It consists of one input terminal (Pole) and one output terminal (Throw). It provides straightforward **ON/OFF control** for a single electrical circuit, completing or breaking the current path between power source and load.

Terminal Configuration

Pole (1)

Common supply feed connection point.

Throw (1)

Single downstream load routing terminal.

Circuit Paths 1 Conductive Track
Default Contact State Normally Open (NO) / OFF

Assembly & Materials

  • •
    Insulating Base Plate: Non-conductive phenolic bakelite or ceramic base preventing electrical leakage to ground.
  • •
    Input Terminal Post (Pole): Brass stud or screw clamp connected directly to incoming line voltage.
  • •
    Output Terminal Post (Throw): Contact clip stud connected directly to load circuit.
  • •
    Movable Conductive Arm: Phosphor bronze or brass contact bar bridging the two terminal posts when actuated.

Laboratory Experiments & Wiring Procedure

Experiment 1: Single Lamp Control Setup Connect live AC line to Pole terminal screw. Wire Throw terminal screw to lamp socket terminal 1. Connect lamp socket terminal 2 to neutral. Toggle SPST switch to verify ON/OFF illumination.
Experiment 2: Contact Resistance Measurement Measure voltage drop (Vdrop) across closed SPST contacts under load current (I). Calculate contact resistance using Rc = Vdrop / I.
