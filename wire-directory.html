Max Allowed Voltage Drop

Standard code recommendations limit total voltage drop to 3% for branch lighting circuits and 5% for heavy power loads to ensure efficient operation.

Continuous Load 80% Rule

For continuous loads running over 3 hours (e.g. EV chargers, AC units), design the circuit load to not exceed 80% of the wire rating.

Copper vs. Aluminum Rule

Aluminum provides ~61% conductivity of Copper. When substituting, select one size larger Aluminum conductor compared to Copper.
